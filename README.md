# Meine Mod

Eine Fabric-Mod für **Minecraft Java 1.21.1**. Geplant sind Technik/Maschinen-Elemente und ein Menü an Setzlingen, mit dem Knochenmehl und Knochenblöcke zum Züchten riesiger Bäume verwendet werden.

## Automatischer Build
Bei jedem Push startet GitHub Actions den Build. Nach einem erfolgreichen Lauf findest du die JAR-Datei unter **Actions → erfolgreicher Lauf → Artifacts**.

## Entwicklungsstatus
Das Projekt-Grundgerüst und der automatische Build sind eingerichtet. Die Baum-Mechanik und das Menü sind noch nicht fertig; ich ergänze sie schrittweise und prüfe sie über den Build.
