# Crazy Bike — Fabric 1.21.1

A separate prototype project so the existing MeineMod sources remain untouched.

## Features in this prototype
- Bike-spawner item
- Rideable entity based on Minecraft's pig vehicle controls
- Blocky red/black motorcycle-style renderer
- Small sprint turbo impulse
- Java 21 / Fabric 1.21.1

## Build
Run `gradle build` from this directory with Java 21. The JAR will be in `build/libs/`.

The project is an initial prototype; gameplay and renderer compatibility must be verified by the CI build and in Minecraft.
